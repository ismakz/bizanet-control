# Guide BizaNet Control - Revendeur (Agent)

Bienvenue sur BizaNet ! En tant que `COMPANY_AGENT`, vous êtes responsable de la distribution et de l'activation des accès internet pour vos clients finaux.

## 1. Validation KYC Obligatoire
Avant de pouvoir retirer vos commissions, vous devez faire valider votre identité (KYC) par votre administrateur (Company Admin).
- **Conséquence** : Sans KYC validé (`APPROVED`), vous pouvez vendre des tokens, mais l'option de retrait ou de transfert d'argent sera bloquée.

## 2. Vente Rapide (Quick Sale)
L'outil **Quick Sale** vous permet de vendre directement de l'internet.
- Entrez le numéro de téléphone du client.
- Sélectionnez le forfait.
- Encaissez l'argent en espèce ou par mobile money.
- Le token est automatiquement généré et activé pour le client.

## 3. Gestion des Tokens
Vous pouvez générer des tokens en avance pour les imprimer ou les vendre plus tard.
Faites attention au type d'accès :
- **WiFi** : Le client se connecte au réseau sans mot de passe puis entre son token sur la page d'accueil BizaNet.
- **Câble** : Le client branche son câble, ouvre la page d'accueil. S'il n'est pas détecté, il devra saisir son adresse MAC.
- **PPPoE** : Le client (ou vous) configurez son routeur avec le token comme nom d'utilisateur et mot de passe.

## 4. Wallet (Portefeuille) & Transferts
Votre portefeuille affiche vos commissions accumulées.
- **Retrait** : Vous pouvez demander un retrait vers votre compte Mobile Money. L'admin approuvera la transaction.
- **Transfert** : Vous pouvez transférer de l'argent de votre portefeuille vers un autre Agent de votre entreprise (nécessite un KYC valide).

## 5. Support Client
Si un client change de téléphone, son token sera bloqué (Anti-fraude).
Il fera une **Demande de changement d'appareil** via le portail.
Vous pourrez approuver ou rejeter cette demande dans l'onglet "Appareils".
